5.1 两道硬门 + 一个运行时门

G1 结构门
plugin.json 的 serverEntry 所指文件必须 existsSync；缺 → ENTRY_MISSING → 整插件被拒 → /api/health 报 error → Web 面从不挂载（曾导致 auto 项目永久 Loading…）。这就是两个 no-op server 入口必须存在的原因。
G2.5 模式门
插件目录名必须与 manifest 的 modes 一致，否则 MODE_MISMATCH。运行时另有 HTTP 层 PLUGIN_MODE_MISMATCH。
HOST_MODE / guardian
HOST_MODE=manual|auto|all 裁掉不匹配插件（status=skipped，留在状态表可查）；外部插件由 guardian 灰度——连续 2 个会话零错误才放行。
