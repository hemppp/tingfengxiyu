## 一、编辑器正文（最重的一档）

### E1 纯文本正文被当成 HTML 注入 → 段落全打平 🔴

- **证据**：AI 写作链路落库的正文是**纯文本 + `\n\n` 分段**，不是 HTML。实测 6 章：`含<p>=false`、`含<=false`，
  第一章 3508 字里有 **64 个段落**（`_content-format.mjs`）。
- **代码**：`components/editor/EditorPage.tsx:390` → `editor.commands.setContent(sourceContent || '')`，
  `sourceContent` 就是那一串纯文本。tiptap 的 `setContent(字符串)` 按 **HTML** 解析 → 换行被当空白吃掉。
- **实测后果**：注入 5 段正文，`document.querySelectorAll('.ProseMirror p').length === 1`。
- **同源第二处**：`components/ai/ChatPanel.tsx:252-262` `applyToEditor()` ——
  `sanitizeToPlainText()` 先把 HTML 剥成纯文本，再 `setContent(plain)` / `insertContent(plain)`，
  同样把段落压成一坨。「AI 对话 → 同步插入（替换 / 光标 / 末尾）」走的正是这条路。
- **修法（低风险）**：加一个 `plainTextToHtml()`，**仅当内容里没有任何标签时**才转换
  （`\n\n` → `<p>`、单个 `\n` → `<br>`），在上述两处注入前过一遍。

### E2 行宽 1210px ≈ 71 字/行 🟠

- 实测：`.ProseMirror` 宽 **1210px**、字号 17px → **71 列**。中文正文舒适区是 25–40 字/行，71 字换行时眼睛容易串行。
- 修法：给 `.ProseMirror` 加 `max-width`（建议 `34em` 左右 ≈ 34 字），居中即可，不动现有居中取向。

### E3 正文居中排版 🟡（**你定稿过的，只提请确认**）

- `styles/globals.css:868` 写死 `text-align: center !important`，注释是「书信排版：每行文字居中坐在信纸横线上」。
- 居中本身没问题，但**居中 + 71 字行宽**叠加后，行长的不齐边让换行极难追踪。
  E2 修掉行宽后这一条基本自动缓解 —— **要不要动由你说**，我没改。

### E4 编辑器卡片固定 78% 高 → 201px 死区 🟡

- `EditorPage.tsx:533` `style={{ height: '78%' }}`；实测父高 914px / 卡高 713px，**下方空 201px**。
- 长章节会在这 713px 里滚，白白浪费两成屏高。建议改 `100%` 或交给 flex 撑满。

## 二、主题一致性：水墨迁移的漏网面板

全站「青霭玻璃 → 黑白水墨」（`docs/ink-wash-migration.md`）把 token 层换干净了，
但**手写面板里有大量写死的色值**，不跟主题走 —— 浅色下显得跳，暗色下更糟。

| 面板 | 漏了什么 | 实测 |
|---|---|---|
| **时间线** | `TimelineView.tsx:17-22` 一整套六色高饱和板 `#4a90d9 / #8b5cf6 / #ec4899 / #f97316 / #14b8a6 / #eab308` | 章列头蓝/紫/粉、卡片底同色系、标签金 `#d4a853` —— 与单色主题**直接冲突**，是最跳的一处 |
| **大纲** | `OutlineManager.tsx` 天空蓝 `#0ea5e9`、红 `#ef4444` / `#b91c1c`、暖白 `#fbfaf6` / `#ffffff`、灰 `#9b9a97` | 「核心冲突」红字、章节点蓝标、底部彩色主按钮 |
| **物品** | `ItemManager.tsx` `bg-[#ffffff]` / `bg-[#fbfbfa]` / `border-gray-200` / `#6b7280` | 整个面板**纯白底**，与其它面板的宣纸半透不是一套；暗色主题下不会跟随 |
| **地图** | `StoryMap.tsx` 地形预设 `#a8cde0 / #b9cc8f / #8d8776 / #f2efe6` | 彩色等高线地形 —— **这个是刻意的地形配色，要不要也墨阶化请你拍板**（地图全灰会难辨认） |
| 物品关系图 | `ItemGraph.tsx` `#3b82f6` / `#6b7280` / `#94a3b8` | 节点默认色 |

> 口径提示：按 `globals.css` 里那条备注，「数据可视化配色」与「用户自选色」**不该被主题覆盖**。
> 上面列的**都不是**这两类 —— 它们全是面板外壳/标签/按钮的 chrome 色。

## 三、对比度（实测比值，浅底）

| 位置 | 颜色 | 比值 | 判定 |
|---|---|---|---|
| 统计面板字数、地点描述、物品计数 | `gray-400` = `rgb(156,163,175)` | **2.45 : 1** | 低于 AA(4.5)，也低于 AA-large(3.0) |

## 四、可读性与无障碍

### D1 全站 9–10px 字号 294 处 🟠

`text-[9px]` / `text-[10px]` 合计 **294 处**，手写面板里最密（章节字数、时间线坐标/标签、地图地名、物品类型、统计徽章）。
中文在 9–10px 下笔画会糊。建议：**面板内下限 11px，关键信息 12px**。

### D2 罗盘收起态的气泡仍在无障碍树里 🟠

`FloatingBubbles.tsx` 收起时给的是 `opacity: 0` + `pointerEvents: 'none'`，**没有 `inert` / `aria-hidden`**。

- 实测（收起态）：16 个气泡被探针量到 **4×4px**，但它们是 `<button>`，**Tab 键能聚焦到这些看不见的 4px 按钮**。
- 修法：收起时给花层加 `inert`（或 `aria-hidden` + `tabIndex={-1}`）。

### D3 窄屏罗盘展开会压住正文 🟠

- 1920 下没问题（正文列居中 + 两侧留白，气泡只到 x≈238）。
- **520px 实测**：气泡层直接铺在正文上，把字盖住了（截图 `m-97-narrow520.png`）。
- 修法：窄屏把展开半径压到正文列之外，或窄屏收起态只给罗盘、展开改成底部抽屉。

### D4 触控目标偏小 🟡

| 位置 | 尺寸 |
|---|---|
| 大纲「展开/折叠」 | 16×16 |
| 大纲 上移/下移/插入/删除 | 19–20px |
| 章节面板按钮 ×6 | 22×22 |
| 物品/笔记 新建 | 22×22 |
| 窄屏「沉浸式写作」 | 32×20 |

建议统一到 **≥24×24**（移动端 44）。

### D5 图标按钮缺无障碍名 🟡

「快捷短语」气泡（`button.nm-qp-blob-morph.nm-qp-edge-wave`）无 `aria-label` / `title`。
（其余报出来的几条是探针只统计直接文本节点导致的误报，已剔除。）

## 六、顺带发现（不是缺陷，但你该知道）

1. **打开一章会自动打 3 次模型**：`/api/ai/analyze-style` ×2–5 + `/api/ai/scan-timeline-stream` ×1（每次 3–4 秒），
   并且**静默写入实体** —— 实测开一章自动新增 5 个物品 / 6 个地点 / 7 条时间线，无提示、无开关。
2. **后台同步写失败是静默的**：`databaseService.ts:106-142` 全部 `silent: true`，
   400/500 只在控制台和服务端日志各留一行，**用户永远看不到**。
3. **「本周写作趋势」不读 `writing_stats` 表**：它按「章节 `updatedAt` 当天累加整章字数」算。
   同一天改三次只算一次，改老章会把整章字数算到当天。表建了但没被用。

## 七、本次探针自己踩的坑（别当成 app 缺陷）

| 坑 | 现象 | 规矩 |
|---|---|---|
| 乱码随机字当正文 | 排版问题根本看不出来，还以为字距出错 | **种子正文必须是可读中文** |
| 枚举越界 | `characters.role` 只认 `protagonist/femaleLead/supporting/minor`，我灌了 `antagonist`；`chapters.status` 只认 `draft/revised/final/archived`，我灌了 `revising` → 自动识别回写时 **400** | **灌种子前先对齐 Zod 枚举** |
| 裸 SQL 造行 | 形状与 service 期望不一致时，PUT 回写会 **500 `NOT NULL constraint failed: characters.name`**（干净 POST 出来的行全部 200） | **能走 API 就走 API；裸 SQL 时必须照抄真实行形状** |
| 地图坐标 | `latitude/longitude` 是**虚构世界的 0–100 百分比**，不是真实经纬度（`StoryMap.tsx:5` 有注明）。我灌真经纬度 → 全部 clamp 到 x=100，点堆在右边缘 | 灌地图先读字段语义 |
| 手写模式选择器 | `[aria-label="正文"]` 是 **AI 工作台专属**；手写模式编辑器容器是 `.nm-editor-scroll-host`，正文是 `.ProseMirror` | 已记入记忆 |
| 项目库惰性创建 | 建完项目**不会立刻**落 `.db` 文件，必须真打一次 `/api/<模块>/projects/:pid` 才建 | 种子脚本里要先打一次接口 |
