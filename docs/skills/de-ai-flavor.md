【已激活技能：去 AI 味】

任务：让中文文本读起来像人写的，而不是模型生成的。
**判定靠多类痕迹在同一段里聚集；单个痕迹不定罪 —— 宁可漏报，也不要把干净的稿子改花。**

═══ 总纲判据（删除测试）═══
把这个词或这句话删掉，读者损失了什么信息？说不出损失什么，就删。
对「给内容定性」的短语，两头都能判：删掉后读者从后面的事实里读得出这个定性 → 这个短语是废的；
读不出 → 定性本身站不住。两种结果都是删。

═══ 1. 排版层（读者判「这是 AI 写的」通常不超过三秒）═══
· emoji 小标题（`## 🚀 核心优势`）→ 全删，标题只留文字
· 加粗轰炸（每项都是 `**关键词**：解释`）→ 一屏 ≤2 处，只留真结论
· 机械列表（正常叙述被拆成 5 条平行短句、每条一行）→ 能连成段的连成段
· 分隔线滥用（每两段一条 `---`）→ 只在真正换大节时用
· 三级标题过密（300 字里三个小标题）→ 短文不分节
· 表格癖（两三个要点也做表）→ 少于三行三列改句子
· **每段等长**（段段 3–4 行，节奏平坦）→ 故意留一两个一句话的短段

═══ 2. 词汇层 ═══
· **高频 AI 词**（密集出现才是信号）：赋能 抓手 闭环 维度 格局 生态 链路 心智 颗粒度 深耕 沉淀 复盘
  对齐 拉齐 打法 势能 跃迁 范式 底座 护城河 全链路 端到端 一站式 无缝 丝滑 极致 至关重要 核心关键
  深入探讨 深度解析 全面剖析 彰显 凸显 诠释 见证 织就 绘就 赋予 日益 愈发 崭新 蓬勃
· **翻译腔**（英文模板直译）：作为……的证明 / 在不断演变的……格局中 / 值得注意的是 / 让我们深入探讨 /
  这不仅仅是……更是…… / 无缝的直观的强大 / 在当今快速发展的时代 / 释放……的潜力 / 拥抱变化 · 引领未来
  → 删掉，或换成具体能力
· **句法翻译腔**：长定语链拆成短句；被动堆叠改主动；「基于……」「通过……来……」「对于……而言」
  「在……方面」「从……的角度来看」多数可直接删
· **空心动词**（名词化抽空动作）：「进行了深入的探索」「实现了效率的提升」→ 还原动词 + 具体宾语
  （「实现了效率的提升」→「构建时间从 20 分钟降到 6 分钟」）
· **过度限定**（可能 / 通常 / 在某种程度上 / 一般而言 堆在一起）→ 一句最多一个
· **绝对化词**（所有人 / 永远 / 从不 / 无一例外）→ 改成有边界的表述
· **工程师腔 / 调试腔**（稳稳兜住 稳稳接住 收口 收敛 砍一刀 打掉 落盘 兜底 压实 锁住 对上了 坐实了
  口径 抠出来 揪出来 我不猜 根因）→ 非技术场景就是强信号。**误判防护**：真故障报告 / changelog /
  带具体参数的调试里是正常术语，不动
· **自媒体腔**（保姆级 硬核 干货 拆解 盘点 避坑 一文读懂 万字长文 建议收藏 划重点）→ 真人偶尔用，AI 每篇都用
· **抒情词修饰抽象概念**（安放 抵达 微光 褶皱 丰盈 滚烫 轻盈 剥开 锋利 柔软 落在 记忆/成长/时代/情绪 上，
  一段出现两个以上）→ 落在**具体物体**上是正常表达；**文学创作不适用此条**
· **★ 分析腔 / 点评腔（最重要的一类）**——共同点：**先标注，后给内容**，标签本身不携带信息，
  只是告诉读者「注意，重要的来了」。真人靠内容判断轻重，AI 靠标签。
  - 表达自评：直白 / 朴素 / 实在 / 坦白 / 赤裸 →「说得直白点，就是 X」→「X」
  - 重要性标注：值得注意的是 / 值得记住的是 / 这里很关键 / 有意思的是 / 需要指出的是 / 我们来看一下 → 删
  - 内容定性：诚实 / 坦诚 / 最重的一条 / 最关键的一点 —— **词都正常，问题在位置**：
    站在事实前面替读者下结论。评谁不是重点，这个词有没有承担信息才是
  - 分析动词：洞察 / 拆解 / 梳理 / 剖析 / 解构 / 聚焦 → 换成「看出 / 讲 / 列出来」，或删动词直接给结果
  - 伪学术名词：叙事 / 核心价值 / 底层逻辑 / 方法论 → 说清楚具体是什么

═══ 3. 句式层（★ 中文 AI 味最稳定的指纹）═══
· **三元并列**（高效、智能、便捷 / 更快、更稳、更省）—— 留最准的一个；全文允许出现一次
· **否定式排比**（不是 X 而是 Y / 不仅 X 更是 Y / 与其说 X 不如说 Y / 看似 X 却 Y / 问题不在于 A 而在于 B）
  —— 全文最多一次，且要真有对比价值。**只把语序倒过来（「Y，不是 X」）不算改**
· **系动词回避**（作为……的存在 / 扮演着……的角色 / 充当 / 标志着 / 成为了……的代名词）→ 直接用「是 / 有 / 就是」
· **同义词循环**（同一个东西两三句内连续换名，越换越抽象）→ 统一回最具体的那个词。
  **术语重复是精确，换词回避才是 AI 味**；改写时自己也不要靠换同义词来降频
· **预设反驳**（我不是说…… / 需要澄清的是，这并不意味着……）→ 回应了没人提出的反对意见，删掉；
  有人真提过的、正面回答完的保留
· **拒绝假选项**（你可能会想……但 / 一个看似可行的办法是……然而）→ 草稿残留，删；
  设计文档里读者真会考虑的备选方案保留
· **对仗金句癖**（每段结尾都给一句工整短句总结）→ 删掉大部分，留一句都算多
· **设问开场**（什么是 X？简单来说，……）→ 直接从事实开始
· **破折号插入语**（中文里 —— 密集出现是明显信号）→ 改句号断开，或去掉插入部分
· **连接词报幕**（首先……其次……最后 / 此外 / 因此 / 综上所述）→ 段落顺序应靠内容成立；
  删掉后读不通，说明顺序本身有问题
· **结构报幕**（这就是本文后面要用的那把尺子 / 第三节说过的 / 一句话收 / 小结一下 / 接下来我们看）
  → 交叉引用是给编辑看的，不是给读者看的。长文里若不指路读者就跟不上，说明章节顺序有问题
· **句长趋同**（连续三句字数接近）→ 改一句；真人写作长短起伏很大

═══ 4. 结构层 ═══
· 总分总模板（开头定义 + 中间三点 + 结尾升华）→ 从最有信息量的地方开始
· 强行对称（每节都三小点、每点两句话）→ 真实内容不会这么整齐，重要的部分就该写得更长
· 同构小节（相邻小节共用同一套内部结构）→ 换不同的展开方式；全文最多一个编号列表段
· 「挑战与展望」结尾 → 凑数段落，删
· 开头铺垫（「随着……的快速发展，越来越多的……」）→ 删，第一句就给结论或场景
· 结尾升华（「未来已来」「让我们一起拥抱变化」「希望对你有帮助」）→ 收在最后一个具体事实上，
  或收在一个真实的未解问题上

═══ 5. 内容层（★ 最深的一层，前面全改对了也救不回来）═══
· 拔高意义（把普通更新说成里程碑 / 革命 / 重新定义）→ 降回原尺寸
· 模糊归因（业内人士普遍认为 / 研究表明 / 有数据显示 而无出处）→ 补出处或删。
  **不要降级成模糊说法**（「效率明显提升」）—— 那只是把假变得更难查
· **装饰性假细节**（凌晨三点 / 第三杯咖啡已经凉了 / 窗外下着雨）→ 删。
  **这是「注入人味」最常见的翻车方式：假细节比套话更像 AI。**
  用户真实提供的细节、承担因果的细节保留
· 借喻场混用（赛道 / 战场 / 地基 / 风口 / 浪潮 / 护城河，一段里混用三个以上）→ 全还原成字面意思；
  行业里已字面化的词（金融的「杠杆」）不算
· 正确的废话（「平衡好效率与质量至关重要」）→ 删
· 缺具体（全篇没有一个数字、时间、人名、产品名、失败案例）→ 补；
  补具体的信息必须来自原文或用户，缺就列出来问
· 只有好消息 → 真实经验里一定有代价、妥协、走过的弯路，写出来

═══ 6. 对话痕迹（从聊天粘出来的稿子，交付前必须清干净）═══
· 「这是一个很好的问题」「当然可以」「希望对你有帮助」「如果你需要，我可以进一步……」
· 主动出击腔：「要不要我帮你……」「只要你回复我，我立马开始」
· 表演式坦诚：「我必须诚实地说」「说句实话」「坦白讲」（后面跟的往往是普通信息）→ 删预告，直接说
· 「作为一个 AI 模型」/ 知识截止日期声明
· 「以下是……」开头的交付语
· 章节末尾的「总结：」小节（正文已经说完了）
· 谄媚语气：「您提到的这一点非常关键」

═══ 7. 误判防护（必须遵守）═══
· **技术文档、合同、公告、论文摘要**里的书面语和被动句是**规范**，不是 AI 味 —— 只清理套话和翻译腔
· 引用的原文、他人发言、法条、数据 **一律不动**
· **术语的准确重复不是问题**（同一概念同一篇里就该用同一个词），别为了「变化」制造同义词循环
· 作者本人的口头禅若在样本里反复出现，那是**声音**，保留
· 用户明确要求的正式语气优先
· **单个痕迹不定罪**：一处破折号、一个「然而」说明不了什么。**宁可漏报，不要把干净的稿子改花**
· **散文与小说的文学表达另论**：抒情词、破折号插入、句长起伏在**文学描写**里是正常手法。
  本技能针对的是**非虚构文本**，以及**小说里的叙述性套话**（如章节总结、AI 式的场景铺陈）——
  判断标准：它是「作者在写故事」还是「作者在向读者解说自己的故事」

═══ 8. 交付方式 ═══
① 先给改后的文本（不要边改边解释）
② 再逐行列出实质改动：原作 → 改为 → 为什么。细则不刷屏，只列影响了意思或节奏的改动
③ 若原稿缺少必要具体信息（数字/出处/代价），单独列出来问，不要用模糊说法填坑
